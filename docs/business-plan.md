## 二、資產評估（商業視角）

### 核心資產排序（護城河由深到淺）
1. **16 卡點診斷分類學＋解法映射**——10 年諮詢經驗的結晶，抄不走。這是產品的「作業系統」。
2. **雙迴圈＋雙向校正模型**（W 回報校正 S 自評）——讓產品「越用越準」，結構性留存機制。
3. **S%/W% 量表**——把「自我了解」變成可見進度，訂閱的數字載體。
4. 7 支工具原型——可快速重建，價值在設計而非程式碼。
5. 既有流量資產：官網、3 支上線工具、諮詢客源、演講管道。

### 競爭定位
- vs **GrowMe/Blinkist 類**（內容圖書館）：他們賣廣度，你賣**診斷與轉變**；不打內容戰。
- vs **測評平台**（104職涯測評等）：他們停在「報告」，你接到「行動與回補」。
- vs **真人職涯諮詢**：你不是取代，是**產品化前段＋放大真人的槓桿**。
- **獨特位置：市面上沒有「診斷→行動→回補→重測」閉環的中文生涯產品。**

## 三、產品線規劃（階梯式）

```
L0 免費診斷層   S–W測驗、離職診斷、3支小工具        → 獲客/名單（已有！）
L1 單點工具層   職缺勝率+改寫、決策校準、測評中心      → 低價單購或免費增值
L2 療程層       14/30天卡點突破療程（診斷+骨架+回補）  → 核心變現 v1 ★先做這個
L3 訂閱層       Loop B會員：S%/W%儀表板+重測+持續回補  → 經常性收入 v2
L4 真人層       一對一諮詢/決策校準（既有服務）        → 高單價+兜底（已有！）
L5 B2B層       企業版：留任診斷/內部發展（升級型）     → 遠期選項
```

**關鍵洞察：L0 和 L4 你已經有了。缺的只是中間的 L2——這正是「系統慢慢堆疊」與「直接找真人」之間的斷層，也是目前收入結構裡缺的中間價位帶。**

### 定價假設（台灣市場，待驗證）
| 層 | 定價假設 | 對標 |
|----|---------|------|
| L2 療程 | NT$1,800–3,600／一次 | 線上課程價位帶；約為一對一諮詢的 1/2–1/3 |
| L3 訂閱 | NT$250–450／月（年繳折扣） | 高於內容訂閱、低於教練服務 |
| L4 真人 | 既有定價 | 錨定高點，讓 L2/L3 顯得划算 |

### 各層的漏斗角色
- L0→L2 轉換：診斷結果頁直接推「你的卡點對應的 14 天療程」。
- L2→L4 升級：療程中卡住／想更快 → 真人（邏輯4 已內建）。
- L2→L3 續留：療程結束時展示 S%/W% 成長與「W 會衰減」→ 訂閱維持。
- L4→L3 回流：諮詢結案的客戶轉入訂閱做長期追蹤（諮詢師的「售後」）。

## 四、90 天行動方案（先療程、後訂閱的落地版）

### Phase 1（第 1–4 週）：把 L2 v1 拼出來——不寫新系統
- 選**一條**最強路徑做首發療程：建議「**突破型 B｜14 天求職突圍**」（職缺勝率＋7天改寫＋專業梳理閉環已全部做完，內容最成熟、受眾最痛、付費意願最高）。
- 交付形式用**最低技術成本**：現有 HTML 工具 ＋ Email/LINE 每日推送 ＋ Google Sheet 記錄（都是你已在用的技術棧）。**不做 App、不做後端。**
- 同步修掉：專業梳理/價值觀的顯示結果問題、網站測驗 3 處 PDF 修正。

### Phase 2（第 5–8 週）：小規模付費驗證
- 從既有名單/社群招 **20–30 位種子用戶**，定價 NT$1,290–1,990（早鳥）。
- 驗證三個數字：**付費轉換率**（診斷完成者→購買 ≥5%？）、**完成率**（14天走完 ≥40%？）、**升級率**（療程→諮詢 ≥10%？）。
- 每日推送內容邊跑邊寫——這同時是在生產 L3 訂閱的內容庫。

### Phase 3（第 9–12 週）：依數據決定下一步
- 三個數字達標 → 加開第二條療程（建議「決策型｜7 天做出選擇」，決策骨架已建好，週期短、見效快）＋開始規劃訂閱層的技術底（帳號＋資料庫，此時才值得投工程）。
- 未達標 → 問題多半在（a）定價（b）推送內容品質（c）診斷→療程的銜接文案；修正後再跑一輪。**仍然不做 App。**

### 明確的「不做清單」（90 天內）
- ❌ 原生 App／跨平台開發（等 L2 驗證＋L3 需求證明後才投）
- ❌ 16 條療程全展開（先 1 條打透）
- ❌ 自建推播/會員系統（用 Email/LINE 官方帳號頂著）
- ❌ B2B（至少 12 個月後）

## 六、風險清單
1. **一人瓶頸**：內容、判斷、真人服務都繫於你。緩解：Layer 2 AI 包裝＋規則化解法庫是解方，療程期間記錄你的每次人工介入，就是未來自動化的規格。
2. **完成率風險**：療程型產品最常死在 day 4–7 流失。緩解：每日任務 ≤15 分鐘＋反思提問＋（可選）小群組同儕壓力。
3. **免費工具吃掉付費**：L0 給太多。緩解：L0 只給「診斷＋方向」，「每日行動骨架＋回補」鎖在 L2（現有測驗已是這個設計，維持）。
4. **版權**：測評題庫需原創/授權版（已標記）；價值觀詞庫為自有資產（已確認）。
5. **技術債**：HTML 原型無資料層。緩解：Phase 3 前用 Sheet/表單頂住；驗證後一次投資資料層，直接按 `measurement-model.md` 建。
