## 三條關鍵迴圈
1. **W→S→W 校正**：勝率 ≤6 → 專業梳理 → 重評勝率（雙軸互相校正）。
2. **養成迴圈**：待證明 → 加一分行動 → 分數養起來 → 回評勝率。
3. **Loop B 長期回補**：所有行動 → S/W profile → 重測 → 看成長（訂閱引擎）。
