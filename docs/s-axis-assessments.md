# S 軸 · 三項標準測驗（DISC／Holland／Career Anchor）

> 使用者面顯示名稱：**人格特質測評**（DISC）／**興趣方向測評**（Holland）／**職業價值觀測評**（Career Anchor）。
> 定位：探索B「感知未建立」的核對工具；分別餵養 S 的 **性格／興趣／價值觀** 維度；
> 性格＋興趣可作**長期感知核對**。
> ⚠️ 實作須用**原創或已授權版本**，勿照抄官方版權題本。

關鍵設計：每項測驗「測完不是結束」，而是用**測後追蹤機制**把結果變成可累積的 S 軸資料。

---

## ① DISC → 性格維度
- 測完得性格傾向後 → 列出「該特質的人會有的 **10 種行為**」→ 使用者逐項回答
  **「這是我／這不是我」** → 收錄紀錄。
- **用途**：在**行為層級**核對性格（不只貼標籤）；長期重測看一致性 = 性格維度的品質/穩定分。
- 餵養：性格 %（完成測驗 ＋ 行為核對一致度）。

## ② Holland → 興趣維度
- 測完得興趣方向（碼）後 → 列出 **10 種興趣方向提案** → 使用者逐項回答
  **「我已經做過／我想試試看／我沒興趣」**。
- **用途**：把抽象興趣碼變成**具體可行動的提案**。
  - 「想試試看」→ 可導入 探索A／最小行動體驗（去實際嘗試）
  - 「已經做過」→ 累積進興趣盤點（持續/中斷）
- 餵養：興趣 %（完成測驗 ＋ 提案回應累積）。

## ③ Career Anchor → 價值觀維度（職業價值觀測評）
- **計分改用排序**（Likert 會多項滿分、分不出來）：4 題（工作型態／薪酬方式／發展機會／認同價值），
  每題 8 個敘述對應八錨，使用者**排前四名**：第1名4分→第4名1分；四題加總，**最高＝主要錨定、次高＝次要錨定**。
- 結果頁顯示**主要＋次要錨定**及其對應價值觀名詞。
- 測完 → 把主要＋次要錨定對應的價值觀**注入價值觀清單**（候選池）→ 與價值觀探索/決策骨架打通。
- 餵養：價值觀 %；並讓結果成為價值觀排序的候選來源。
- 校訂：原「認同價值」第3項（自主獨立型）描述為「公開表揚、獎章獎牌」，不符自主獨立，已改為
  「自己能以獨立、自主的方式完成工作並受到尊重，工作成果由自己定義，不被過度規範或干涉。」

### 八錨 → 3 價值觀（已校：全部取自你的 84 詞庫）
| Career Anchor（Schein 八錨） | 對應 3 價值觀 |
|---|---|
| 技術／職能型 | 專業、品質、學習 |
| 管理型 | 領導、影響力、權力 |
| 自主／獨立型 | 自由、獨立、彈性 |
| 安全／穩定型 | 穩定、平靜、和平 |
| 創業型 | 創新、創造、冒險 |
| 服務／奉獻型 | 利他、助人、意義 |
| 純粹挑戰型 | 挑戰、競爭、目標 |
| 生活型 | 平衡、家庭、健康 |

> 24 個對應值彼此不重複，且全部存在於官方 84 詞庫 → Career Anchor 結果可直接注入價值觀清單候選。
> 若用詞要更貼你的諮詢語氣，再微調即可。

## 與量表/維度的關係（見 `measurement-model.md`）
- DISC → 性格 %；Holland → 興趣 %；Career Anchor → 價值觀 %。
- 三者皆可作**長期感知核對**（重測穩定度＝該維度的品質分）。
- Career Anchor 與「價值觀探索」共用價值觀清單，形成閉環：測驗給候選 → 排序與打分 → 加一分行動。
